# Bolsa Família e Mercado de Trabalho

Este projeto apresenta uma análise de dados do IBGE sobre o mercado de trabalho e o Bolsa Família, utilizando a linguagem R.

O objetivo é explorar indicadores do mercado de trabalho brasileiro e analisar a situação ocupacional de moradores de domicílios beneficiários do Bolsa Família, com base em dados da PNAD Contínua.

## Acesse o relatório

**[Clique aqui para acessar o relatório completo](https://manualdocientista-mc.github.io/desempredgo-bolsa-familia/)**

No relatório, você encontrará gráficos, tabelas, análises e explicações metodológicas.

## Fontes de dados

- **IBGE:** dados da PNAD Contínua e indicadores do mercado de trabalho.
- **SIDRA/IBGE:** dados estatísticos disponibilizados pelo sistema de recuperação automática do IBGE.

## Metodologia

A análise é desenvolvida em R, com procedimentos de importação, tratamento, organização e análise dos dados, além da elaboração de tabelas e gráficos.

Os resultados devem ser interpretados considerando os conceitos estatísticos, as características das bases utilizadas e as limitações metodológicas da análise. A presença de moradores em domicílios beneficiários do Bolsa Família não significa, por si só, que todos os integrantes dessas famílias recebam o benefício ou estejam desempregados.

## Tecnologias utilizadas

- R
- PNAD Contínua
- SIDRA/IBGE
- R Markdown

## Objetivo do projeto

Disponibilizar uma análise transparente e consultável, permitindo que outras pessoas conheçam os dados utilizados, compreendam os procedimentos adotados e avaliem os resultados apresentados.
